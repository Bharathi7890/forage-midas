# J.P. Morgan Chase & Co. – Advanced Software Engineering Virtual Internship (Java + Spring Boot)

This repository contains my completed tasks for the **J.P. Morgan Chase & Co. Advanced Software Engineering Virtual Experience Program** hosted on [Forage](https://www.theforage.com/).  
The program provided hands-on experience simulating how software engineers at J.P. Morgan Chase build and enhance enterprise-level financial systems using **Java**, **Spring Boot**, **Kafka**, and **microservice architecture**.

---

## 🏢 Overview

During this virtual internship, I worked on enhancing a **financial transaction processing system** that integrates multiple services such as client data, trade execution, and analytics.  
The focus was on **backend development**, **data streaming**, and **system reliability**, following real-world engineering standards used by J.P. Morgan Chase.

---

## 💻 Tasks Completed

### **Task 1: Environment Setup & Project Build**
- Configured a **Spring Boot microservice** application.
- Set up **Apache Kafka** and **Zookeeper** for event-driven communication between services.
- Built and tested the project using **Maven**.

### **Task 2: Implement Data Flow Between Services**
- Established **producer-consumer communication** using Kafka topics.
- Published and consumed messages between microservices to simulate trade data flow.
- Verified data serialization using **JSON** and **Avro** formats.

### **Task 3: Improve System Reliability**
- Implemented **logging and monitoring** using SLF4J and Logback.
- Added **exception handling** and fallback mechanisms for failed message consumption.
- Optimized message processing and ensured high system throughput.

### **Task 4: Testing & Debugging**
- Wrote **unit tests** and **integration tests** using JUnit and Mockito.
- Debugged issues related to Kafka connectivity and Spring Boot configuration.
- Ensured all microservices communicated successfully under simulated trading loads.
